# Translator App

This is a simple translator app that uses Google's NMT model to translate text from one language to another.
The app consists of client built with React.js, and interacts with APIs like Google Translate API, Text-to-Speech API, and Speech-to-Text API.

## Files

- `client`: A React.js frontend for the translator app.
- `node_client`: A Node.js client demonstrating the usage of Google Translate API, Text-to-Speech API, and Speech-to-Text API.
