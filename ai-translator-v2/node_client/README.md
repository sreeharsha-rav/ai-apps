# Node Clients for Google Cloud APIs

This is a Node.js client library for Google's Cloud Translation API, Text-to-Speech API, and Speech-to-Text API. It is intended to be used in conjunction with:
- [Cloud Translation API - Basic v2](https://cloud.google.com/translate/docs/basic/translate-text-basic)
- [Text-to-Speech API](https://cloud.google.com/text-to-speech?hl=en)
- [Speech-to-Text API](https://cloud.google.com/speech-to-text?hl=en)

## Files

- `translate.js`: Contains the code for the Cloud Translation API.
- `tts.js`: Contains the code for the Text-to-Speech API.
- `stt.js`: Contains the code for the Speech-to-Text API.
