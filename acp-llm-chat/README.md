# UCP LLM Chat

This is a LLM chat application that implements UCP (Unified Commerce Protocol), showcasing agentic commerce enabled by this protocol.

## Tech Stack
- **server :** FastAPI, OpenAI, Shopify Catalog MCP, Shopify Checkout MCP
- **client :** Next.js, Zustand, Tanstack Query, Tanstack Virtualizer, TailwindCSS
